# Idioma EN/PT — toggle com tradução offline gratuita

## Requisito
Botão no topo do painel para alternar **inglês original ↔ português**. Sem ferramenta paga.
Conteúdo importado (open5e) é em inglês; o seed curado já é pt-BR.

## Estratégia (offline, grátis, com cache)
```yaml
preferencia:
  guardada_por_usuario: "localStorage idioma=pt|en (toggle na topbar)"
conteudo:
  campo_idioma: "cada registro tem idioma ('en' ou 'pt')"
  pt_nativo: "seed curado já é pt -> mostra direto"
  en_importado: "traduzido sob demanda quando idioma=pt"
traducao:
  motor: "Argos Translate (offline, MIT, modelo en->pt gratuito) no backend"
  sob_demanda: "traduz nome/descrição na primeira vez que é pedido em pt"
  cache: "grava a tradução no DB (tabela Traducao: chave=tipo+slug+campo -> texto_pt)"
  fallback: "se o motor não estiver disponível, mostra o original + selo 'sem tradução'"
endpoint:
  "GET /reference/<tipo>?idioma=pt"   # devolve já traduzido (do cache; traduz e cacheia se faltar)
```

## Por que Argos Translate
- 100% **offline** e **gratuito** (sem API key, sem custo por chamada).
- Roda no container backend; baixa um modelo en→pt uma vez (~algumas centenas de MB).
- Qualidade "boa o suficiente" para estudo (não profissional) — aceito pelo dono.

## Custo/robustez (sinalizado)
- Adiciona peso à imagem (modelo de tradução). Tradução é **lazy + cacheada**, então só paga uma
  vez por item exibido em pt.
- Alternativa mais leve (a confirmar na Fase 6): traduzir só **nomes** e campos curtos; manter
  descrições longas em inglês com o toggle.

## Implementação (as-built, Fase 6)
- Modelo `Traducao(tipo, slug, campo, idioma, texto)` (cache); migração `f3fb253e632d`.
- Serviço `Tradutor` (`app/services/tradutor.py`): traduz via **Argos Translate** se instalado,
  senão **fallback** (devolve original, `traduzido=False`). `aplicar()` só traduz `idioma != 'pt'`
  e cacheia.
- `GET /catalog/<tipo>?idioma=pt` e `/reference/{weapons,armor,items}?idioma=pt` aplicam tradução.
- Frontend: botão **🌐 PT/EN** na topbar (`auth.js getIdioma/setIdioma`), persistido; cliente
  injeta `?idioma=pt`. Escopo: itens/armas/armaduras (têm `idioma`).
- **MT real**: instalar `argostranslate` + modelo en→pt. Sem ele, mostra o original (sem quebrar).

## Critérios de aceite
1. Toggle EN/PT na topbar persiste a preferência.
2. Conteúdo pt-nativo aparece em pt sem tradução.
3. Conteúdo en em modo pt vem traduzido (cacheado na 2ª vez, sem retraduzir).
4. Sem o motor, cai no original sem quebrar a UI.
